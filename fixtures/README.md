Generados con `python scripts/make_fixtures.py` a partir del prototipo de diseño. **No son datos reales.**

- `grid.csv`: ~580 celdas H3 res 9 alrededor de 3 puntos de ejemplo, con colonia/CP/alcaldía/población ficticias. Base para correr los temas sin datos de D1.
- `cells.json`: 3 reportes completos en formato `contracts/cell.schema.json` (uno por dirección del prototipo).
- `addresses.json`: las 3 direcciones de ejemplo para el buscador.
